## Entry 1: Running an existing web app on Fire TV

**Task attempted**
Run my web-based fandom portal, Fan Hub Plus, on a Fire TV device / Fire TV simulator.

**Steps taken**
1. Created an Amazon developer account and read the Fire TV documentation.
2. Set up the required tools and the Fire TV simulator.
3. Tried to package and open my existing web application on Fire OS.

**Expected result**
After following the documentation, the web app would open and run on the Fire TV simulator without much extra setup.

**Actual result**
The setup needed several extra tools, and it was not clear how an existing web application should be packaged and tested for Fire OS.

**Severity**
Medium

**Workaround used**
I followed the documentation step by step and tested the app in the simulator until the main screens loaded and could be navigated.

**Actionable suggestion**
Add a short step-by-step guide for packaging and running an existing web app on Fire TV and the simulator, with a simple "hello world" example.
